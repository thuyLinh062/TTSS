# TTSS - Bai tap Tinh toan song song (OpenMP)

- **TTSS1**: Tinh tich vo huong hai vector (dot_product) ho tro tuan tu (seq) va song song (omp).
- **TTSS2**: Tan cong tu dien do ma bam SHA-256 (dict_attack) ho tro tuan tu (seq) va song song (omp).

## Cach chay
1. Mo TTSS.sln bang Visual Studio, chon cau hinh **Release | x64** va bat OpenMP (/openmp).
2. Nhan Ctrl + Shift + B de bien dich.
3. Chay truc tiep .\x64\Release\TTSS1.exe hoac .\x64\Release\TTSS2.exe de mo menu tuong tac.
